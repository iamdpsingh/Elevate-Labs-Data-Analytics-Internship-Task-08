# 📊 Simple Sales Dashboard Design – Power BI

## 📝 Objective
Create a clean, interactive sales dashboard using **Power BI** that displays sales performance by **Product Category**, **Region**, and **Month**.

---

## 📁 Dataset
**Superstore_Sales.csv**

**Key Columns Used:**
- `Order Date`
- `Region`
- `Category`
- `Sales`
- `Profit`

---

## 🛠 Tools Used
- **Power BI** (for data visualization)
- *(Optional)* Python + Pandas (for data cleaning if needed)

---

## 📌 Steps Followed

1. **Imported Dataset**: Loaded `Superstore_Sales.csv` into Power BI.
2. **Date Transformation**: Converted `Order Date` to **Month-Year** format using DAX.
3. **Created Visuals**:
   - 📈 **Line Chart**: Monthly Sales trend
   - 📊 **Bar Chart**: Sales by Region
   - 🍩 **Donut Chart**: Sales by Category
4. **Filter Added**: Implemented **slicer** for Region selection.
5. **Design Enhancements**:
   - Applied color formatting to highlight top-performing regions and categories.
   - Used consistent layout for readability.

---

## 📷 Deliverables

- 📸 **Screenshot/PDF**: Dashboard exported as image or PDF.
- 🗒 **Insights (Text/Slide)**:
  1. *"The West region recorded the highest sales in Q3."*
  2. *"Technology category consistently outperformed others in monthly sales."*
  3. *"Sales spiked during November and December, indicating seasonal trends."*

---

## ✅ Outcome
Built a functional Power BI dashboard that visually communicates business performance and allows interactive filtering by **Region** or **Category**. This helped in deriving meaningful insights and patterns from sales data efficiently.
